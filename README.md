## Open Engineering Principles

- **Transparency without compromise:** Only public APIs, verifiable open datasets, and client-side reference tools are published here — never private server infrastructure, internal endpoints, or credentials.
- **Non-custodial & privacy-first:** Payment gateways never store merchant private keys; directory badges use zero JavaScript and zero tracking cookies.
- **Standards-first syndication:** Open JSON, OpenAPI 3.1, RSS 2.0 Media, WebSub, and Google News XML Sitemap compliance.
